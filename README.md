# Student Management System

A web-based Student Management System developed using ASP.NET Core, Razor Pages, and SQL Server.

## Features
- Student Management
- Teacher Management
- Attendance Management
- Student Marks Management
- Dashboard
- User Authentication

## Technologies Used
- ASP.NET Core
- Razor Pages
- SQL Server
- HTML
- CSS
- JavaScript
- Entity Framework Core

## Project Structure
- Admin Module
- Teacher Module
- Student Module
- Attendance Module
- Marks Management Module
